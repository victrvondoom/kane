# Downloaded games and licences

These five games are third party projects, not games written for this repository. Only configs, build tooling and a download manifest enter git. `python -m tools.fetch_games` fetches snapshots into ignored `games.cache/`, verifies the archive SHA-256, and never builds or runs them. Licence files stay with each cached snapshot. The first four commits, licence texts and archive hashes were read on 28 October 2026; the chess snapshot was read on 30 October 2026.

Hextris is GPLv3 and is used for local play. We do not ship its files. Breakout's root licence also identifies the sounds as CC BY-ND 2.0 and links to the authors' attribution list. Its `sound/license.txt` covers the bundled sound library under BSD. Preserve all upstream notices in the cache. Sound starts off and the config asks the player to leave it off; the proposed montage uses silent video. No game assets are copied into this repository.

The exact archive URLs and the SHA-256 values computed from their downloaded bytes are in `tools/games-manifest.json`. The first four snapshots include an `index.html` and run as static pages without a build step, based on source inspection. Each ran in a browser on 28 October 2026 (see below). Each game uses the existing adapter with zero new Python lines per game. The fetcher is shared download code, not a game adapter.

React Chess is fetched at the pinned commit above and needs a bundling step: `python tools/build_chess.py`. Its source stays out of git and is unchanged by the build. The script installs esbuild 0.25.0 and React and React DOM 16.13.1 under ignored `games.cache/`, then writes a static page, JavaScript, CSS and the MIT licence to `games.cache/react-chess/dist`. React 16.13.1 satisfies the snapshot's requested versions. The footer credits Cburnett's piece pictures and lists GFDL, CC BY-SA 3.0, BSD and GPL alternatives; that notice stays with the game. The piece pictures load from remote `https://upload.wikimedia.org/` addresses. The local page shell omits the upstream template's analytics script. The separate Chess page in `game/` uses Unicode glyphs and makes no network requests.

All four expose readable state. 2048 stores its board through `LocalStorageManager`; this saved board disappears after a loss. Hextris exposes `score`, `gameState` and `MainHex`. Tetris exposes `rows`, `score`, pieces and the board. Breakout exposes its live instance as `Game.current`. The config expressions only read these values. They do not install hooks or change the game files. None supplies a replay frame counter, so frame locking stays off, reports show "Not reproducible", and recordings use real time. On 28 October 2026 one goal run each, with state text on, won its small goal: 2048 in 12 steps, Hextris in 5, Tetris in 10 and Breakout in 2 (`docs/receipts/runs/i5-2048/result.json` and the three beside it). The goals are small, and each run filed 0 reports.

Upstream pages can contain external fonts, analytics, ads or score requests. The existing `--offline` option blocks remote requests in the browser and in Python, so use it only with a local model; it also blocks the paid model service. No external page scripts were executed during the licence and source review.
