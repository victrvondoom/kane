# Nine-Layer Sparse Autoencoder (SAE) Interpretability Lab

## 1. Overview & Research Mission

The **Nine-Layer Sparse Autoencoder Interpretability Lab** provides deep mechanistic interpretability for neural model activations inside SHIPPROOF.

Sparse Autoencoders decompose dense hidden representations $x^{(l)} \in \mathbb{R}^{d_{\text{in}}}$ at discrete layer $l$ into an overcomplete, highly sparse dictionary of interpretable monosemantic feature directions $f^{(l)} \in \mathbb{R}^{d_{\text{sae}}}$:

$$x^{(l)} \approx \hat{x}^{(l)} = W_{\text{dec}}^{(l)} f^{(l)} + b_{\text{dec}}^{(l)}$$

where $d_{\text{sae}} \gg d_{\text{in}}$ and $\|f^{(l)}\|_0 \le k \ll d_{\text{sae}}$.

The lab monitors **nine discrete layers** ($l \in \{0, 1, 2, 3, 4, 5, 6, 7, 8\}$), provides **calibrated thresholding**, registers firing features with **human/model provenance**, traces inter-layer feature propagation via a **cross-layer DAG** (distinguishing correlation from causation), conducts **causal steering experiments**, and computes standard **reconstruction quality metrics**.

---

## 2. Mathematical Formulations

### 2.1 TopK Sparse Autoencoder
For activation vector $x \in \mathbb{R}^{d_{\text{in}}}$:

$$z = W_{\text{enc}} (x - b_{\text{dec}}) + b_{\text{enc}}$$

$$f = \text{TopK}(z, k)$$

$$\hat{x} = W_{\text{dec}} f + b_{\text{dec}}$$

where $\text{TopK}(z, k)$ retains the $k$ largest positive activations of $z$ and zeros out all others, ensuring exact $L_0 = k$ sparsity without tuning an $L_1$ penalty hyperparameter.

### 2.2 JumpReLU Sparse Autoencoder
JumpReLU introduces a discontinuous threshold $\theta \in \mathbb{R}^{d_{\text{sae}}}$ to eliminate weak noisy activations:

$$f_i = \begin{cases} z_i & \text{if } z_i > \theta_i \\ 0 & \text{otherwise} \end{cases}$$

$$\hat{x} = W_{\text{dec}} f + b_{\text{dec}}$$

### 2.3 Reconstruction Quality Metrics

1. **Reconstruction Loss (MSE):**
   $$\mathcal{L}_{\text{recon}} = \frac{1}{N} \sum_{i=1}^{N} \|x_i - \hat{x}_i\|_2^2$$

2. **Explained Variance ($R^2$):**
   $$R^2 = 1 - \frac{\sum_i \|x_i - \hat{x}_i\|_2^2}{\sum_i \|x_i - \bar{x}\|_2^2}$$

3. **$L_0$ Sparsity:**
   $$L_0 = \frac{1}{N} \sum_{i=1}^{N} |\{j : f_{i, j} > 0\}|$$

4. **Dead Feature Fraction:**
   $$\text{DeadFrac} = \frac{|\{j : \forall i, f_{i, j} = 0\}|}{d_{\text{sae}}}$$

## 3. Cross-Layer Feature DAG (Correlation vs Causality)

Features active at layer $l$ propagate downstream to layer $l+1$. The lab tracks feature trajectories across consecutive layers:

1. **Decoder-to-Encoder Alignment:**
   $$S_{\text{align}}(f_i^{(l)}, f_j^{(l+1)}) = \frac{W_{\text{dec}, i}^{(l)} \cdot W_{\text{enc}, j}^{(l+1)}}{\|W_{\text{dec}, i}^{(l)}\|_2 \|W_{\text{enc}, j}^{(l+1)}\|_2}$$

2. **Coactivation Score:**
   Tracks joint firing conditional probability $P(f_j^{(l+1)} > 0 \mid f_i^{(l)} > 0)$.

3. **Relationship Classification:**
   - **`DIRECT_PROGRESSION`**: High weight alignment ($S_{\text{align}} > 0.6$) and high coactivation ($>0.7$).
   - **`MODULATION`**: Feature at layer $l$ shifts or gates the threshold of feature at layer $l+1$.
   - **`ABSTRACTIVE_MERGE`**: Multiple layer $l$ features converge onto a single higher-order semantic concept at layer $l+1$.

## 4. Causal Feature Steering Interventions

The lab provides an interactive studio to test causal hypotheses by directly intervening on feature activations:

1. **Activation Clamping:**
   Forces feature $j$ at layer $l$ to a fixed value $c$:
   $$f_j^{(l)} \leftarrow c$$

2. **Activation Addition:**
   Adds an intervention vector along feature direction $W_{\text{dec}, j}^{(l)}$:
   $$x^{(l)} \leftarrow x^{(l)} + \alpha \cdot W_{\text{dec}, j}^{(l)}$$

3. **Feature Ablation:**
   Zeros out feature $j$ to test necessity:
   $$f_j^{(l)} \leftarrow 0$$

### Causal Metrics Measured
- **Semantic Drift Score:** Divergence between baseline output and steered output tokens.
- **Side Effect Score:** Measure of off-target feature activation disruptions in unrelated semantic subspaces.

## 5. Feature Registry & Labeling Provenance

Every feature in `sae_features` maintains an immutable record of discovery and labeling:

- **Statuses:**
  - `UNLABELED`: Newly identified feature with automated firing statistics.
  - `MODEL_PROPOSED`: Initial label generated by auto-interpretability prompt.
  - `HUMAN_CONFIRMED`: Inspected and verified by an engineering researcher.
  - `AMBIGUOUS`: Polysemantic or context-dependent feature requiring further sub-clustering.
- **Provenance Tracking:** User email/ID, timestamp, confidence score, activating example tokens, and contrasting non-activating tokens.

## 6. Research UI Interface

The frontend provides:
1. **Interactive 9-Layer Selector:** Jump across Layers 0 to 8 with real-time stats.
2. **Activation Extraction Runner:** Analyze any natural language prompt and visualize firing features.
3. **Feature Labeling Dialog:** Update provisional labels, status, and notes.
4. **DAG Graph Table:** Inspect inter-layer feature correspondences and relationship types.
5. **Causal Steering Controls:** Clamp, add, or ablate features and inspect output diffs.
6. **9-Layer Reconstruction Metrics Dashboard:** Monitor explained variance and dead feature counts across all 9 layers.
